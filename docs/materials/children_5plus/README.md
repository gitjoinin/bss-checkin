# 5세 이상 어린이 자료 관리

## 📋 개요
이 디렉토리는 5세 이상의 어린이들을 위한 Check-In Service 관련 자료를 체계적으로 관리합니다.

---

## 📁 디렉토리 구조

```
children_5plus/
├── README.md                      # 본 문서
├── user_guide/                    # 사용자 가이드
│   ├── step_by_step.md           # 단계별 안내
│   ├── qr_scanning.md            # QR 코드 스캔 방법
│   └── illustrations/            # 그림 자료
├── activities/                    # 어린이 활동 자료
│   ├── check_in_game.md          # 체크인 게임
│   ├── waiting_activities.md     # 대기 시간 활동
│   └── educational_content.md    # 교육 컨텐츠
├── safety_guidelines/             # 안전 수칙
│   ├── safety_rules.md           # 안전 규칙
│   ├── emergency_procedures.md   # 응급 상황
│   └── dos_and_donts.md          # 해야 할 것/하지 말아야 할 것
├── communication/                 # 통신 자료
│   ├── announcement_templates.md # 공지 템플릿
│   └── parent_communication.md   # 부모 소통
└── resources/                     # 기타 자료
    ├── printables/               # 인쇄 가능 자료
    ├── videos/                   # 비디오 자료 링크
    └── images/                   # 이미지 및 아이콘
```

---

## 🎯 주요 컨텐츠

### 1. 사용자 가이드
- **Step-by-Step Guide**: 어린이 친화적인 Check-In 절차 설명
- **QR 코드 스캔**: QR 코드 스캔 방법 가이드
- **삽화 및 그림**: 이해하기 쉬운 시각 자료

### 2. 활동 자료
- **Check-In 게임**: 재미있는 체크인 경험
- **대기 시간 활동**: 지루하지 않게 시간 보내기
- **교육 컨텐츠**: 안전 교육 자료

### 3. 안전 수칙
- **기본 규칙**: 어린이가 이해할 수 있는 안전 규칙
- **응급 상황**: 응급 상황 대처 방법
- **해야 할 것/하지 말아야 할 것**: 명확한 행동 가이드

### 4. 부모와의 소통
- **공지 템플릿**: 부모님께 보낼 공지사항 템플릿
- **안내문**: Check-In 시스템 설명
