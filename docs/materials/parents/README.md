# 부모 자료 관리

## 📋 개요
이 디렉토리는 부모/보호자님들을 위한 Check-In Service 관련 자료를 제공합니다.  
시스템 이해, 사용법, 안전 정보, 자녀 교육 등 다양한 정보를 담고 있습니다.

## 🎯 주요 컨텐츠 구성

### 1️⃣ 시작하기 (Getting Started)
부모님이 처음 시스템을 접할 때 필요한 정보
- 시스템이 무엇인지 이해하기
- 계정 만들고 가입하기
- 첫 체크인 경험하기
- 필요한 앱/웹 다운로드

### 2️⃣ 사용자 가이드 (User Guides)
실제 사용법에 대한 상세한 설명
- 모바일 앱 & 웹 플랫폼 사용법
- QR 코드 스캔 방법
- 알림 설정 및 조정
- 계정 및 프로필 관리

### 3️⃣ 안전 정보 (Safety Info)
부모님이 안심할 수 있도록 하는 정보
- 시스템 안전 기능 설명
- 개인정보보호 정책
- 보안 모범 사례
- 응급 상황 연락처

### 4️⃣ 자녀 교육 (Child Education)
자녀에게 시스템을 가르치는 방법
- 나이별 체크인 교육 방법
- 안전 교육 팁
- 기술 사용 안내
- 아이의 독립성 키우기

### 5️⃣ 소통 자료 (Communication)
시설과 부모 간의 효과적인 소통
- 뉴스레터 템플릿
- 공지사항 예시
- 긴급 공지 방식
- 연락처 안내

### 6️⃣ 문제 해결 (Troubleshooting)
문제가 생겼을 때 참고할 정보
- 자주 발생하는 문제와 해결 방법
- 기술 지원 연락처
- 자가진단 가이드

### 7️⃣ FAQ (자주 묻는 질문)
가장 흔한 질문들에 대한 답변
- 일반 질문
- 요금 관련
- 기술 지원
- 피드백 채널

## 📝 파일 관리 규칙

### 명명 규칙
```
[카테고리]_[제목]_[버전]_[언어].확장자

예시:
- guide_mobilapp_v1_ko.pdf
- faq_general_v2_ko_en.pdf (이중언어)
- poster_safetytips_v1_ko.jpg
- video_tutorial_checkin_link.txt
```

### 지원 언어
- **KO**: 한국어 (기본)
- **EN**: 영문
- **KO_EN**: 한-영 이중언어 (권장)

### 버전 표기
- v1.0: 초기 버전
- v1.1, v1.2: 마이너 업데이트
- v2.0: 주요 개정

### 포맷
- `.md`: 웹 문서
- `.pdf`: 다운로드/인쇄용
- `.jpg/png`: 포스터/이미지
- `.docx`: 편집 가능한 템플릿
