# 📋 자료 작성 템플릿 및 체크리스트

모든 자료 작성자가 참고할 수 있는 가이드라인과 체크리스트 모음입니다.

---

## 📝 문서 작성 템플릿

### 1. 어린이 가이드 템플릿 (Children's Guide)

```markdown
# [제목]

## 🎯 목표
- [목표 1]
- [목표 2]

## 👶 나이 대상
5세 이상 [12세 미만]

## 📚 필요한 것
- [준비물 1]
- [준비물 2]

## 📖 단계별 설명

### 1단계: [단계 이름]
[그림/이미지]
설명: [쉬운 설명]

### 2단계: [단계 이름]
[그림/이미지]
설명: [쉬운 설명]

## ✅ 완료 체크리스트
- [ ] 과정 이해
- [ ] 모든 단계 완료
- [ ] 질문 없음

## 🎉 축하합니다!
[완료 후 메시지]

## 📞 도움이 필요하신가요?
[연락처 정보]
```

### 2. 부모 가이드 템플릿 (Parent's Guide)

```markdown
# [제목]

## 📋 개요
[가이드 개요 - 2-3줄]

## 🎯 이 가이드의 목적
- [목적 1]
- [목적 2]
- [목적 3]

## 📖 상세 설명

### 배경 정보
[필요한 배경 정보]

### 단계별 가이드

#### 1단계: [단계]
[상세 설명]

**팁**: [유용한 팁]

#### 2단계: [단계]
[상세 설명]

**주의사항**: [주의할 점]

## ❓ 자주 묻는 질문

**Q: [질문]**  
A: [답변]

**Q: [질문]**  
A: [답변]

## 📞 추가 도움

| 항목 | 정보 |
|------|------|
| 📧 이메일 | support@checkin-service.com |
| 📱 전화 | 1234-5678 |
| 💬 카톡 | [링크] |

## 📚 관련 자료
- [링크 1]
- [링크 2]

---
**마지막 업데이트**: YYYY-MM-DD  
**버전**: v1.0
```

### 3. FAQ 템플릿

```markdown

### Q1: [질문]?
**A**: [명확한 답변]

**예시**:
- [예시 1]
- [예시 2]

**관련 가이드**: [링크]

---

### Q2: [질문]?
**A**: [명확한 답변]

**더 알아보기**: [추가 정보]

---

## 🆘 해결되지 않은 문제?

문제가 해결되지 않았다면:
1. [단계 1]
2. [단계 2]
3. [고객 지원 연락]

---
**마지막 업데이트**: YYYY-MM-DD
```

## 🎨 포맷 가이드

### 제목 계층
```
# 주요 제목 (H1)
## 부제목 (H2)
### 소제목 (H3)
```

### 강조 표현
- **볼드**: 중요한 용어
- *이탤릭*: 강조
- `코드`: 기술 용어

### 리스트 사용
```markdown
#### 순서 있는 목록
1. 첫 번째
2. 두 번째
3. 세 번째

#### 순서 없는 목록
- 항목 1
- 항목 2
- 항목 3
```

### 표 만들기
```markdown
| 제목 | 설명 |
|------|------|
| 항목1 | 설명1 |
| 항목2 | 설명2 |
```

## 🌐 다국어 작성 가이드

### 한국어 기본 규칙
- 맞춤법 및 띄어쓰기 준수
- 표준 용어 사용
- 존댓말 사용 (부모), 친근한 말 (어린이)

### 영문 추가 규칙
- 번역은 직역이 아닌 의역
- 문화적 차이 고려
- 전문 용어 통일

### 이중언어 형식
```markdown
## English Title / 한국어 제목

**English**: Brief description.

**한국어**: 간단한 설명.
```

## 🖼️ 이미지 가이드

### 이미지 명명
```
[카테고리]_[설명]_[크기]_v[버전].[형식]

예: guide_checkin_500px_v1.png
```

### 이미지 크기
- 웹용: 800px × 600px (최대)
- 모바일: 400px × 300px
- 인쇄용: 300dpi, A4 기준

### 이미지 형식
- 사진: JPG (80% 품질)
- 그래픽: PNG (투명도 필요시)
- 일러스트: SVG (벡터 권장)
